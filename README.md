## 🧭 **Descripción del Proyecto**
Este proyecto tiene como objetivo **familiarizarse con Git y GitHub** mediante la creación, gestión y sincronización de repositorios locales y remotos.  
Incluye pequeños **scripts en Bash** y ejemplos de commits, ramas y control de versiones.

---

## ⚙️ **Tecnologías Utilizadas**
- 🐧 **Linux Mint 22**
- 🧰 **Git y GitHub**
- 🧠 **Visual Studio Code**
- 🪶 **Bash Scripting**
